# МЭС АКС — демо

Интерактивная демонстрация программы МЭС АКС (Мосэнергосбыт): сбор CSV из писем Outlook в сводный Excel, дашборд, задачи по расписанию и подписки юрлиц.

Все данные вымышленные, письма никуда не отправляются.

Это один статический файл `index.html` без сборки. Для публикации на Netlify: **Add new site → Import from Git**, выбрать этот репозиторий, Build command оставить пустым, Publish directory — `.`.
